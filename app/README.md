# Kaan Hamitler — Portfolio

A personal portfolio for a student frontend developer building React projects
and learning TypeScript in public.

## Current focus

- Building and documenting an AI chatbot
- Learning TypeScript through real React projects
- Publishing project repositories with honest case studies

## Stack

- React
- JavaScript
- Tailwind CSS
- Vite
- TypeScript (currently learning)
- EJS (basic familiarity)

## Local development

~~~bash
pnpm install
pnpm run dev
~~~

Before submitting changes:

~~~bash
pnpm run lint
pnpm run build
~~~

Completed projects will be added only when their repository, preview image and
technical explanation are ready.
